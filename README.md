# Temperature Converter

Небольшое веб-приложение на Flask: конвертер температур между градусами
Цельсия, Фаренгейта и Кельвина.

## Маршруты

| Маршрут | Описание |
|---|---|
| `GET /` | веб-страница с формой конвертации |
| `GET /api/convert?value=100&src=c&dst=f` | JSON-API конвертации |
| `GET /version` | версия приложения |
| `GET /health` | проверка, что приложение живо |

## Локальный запуск без Docker

```
pip install -r requirements.txt
python app.py
```

Приложение слушает порт **8000**.
